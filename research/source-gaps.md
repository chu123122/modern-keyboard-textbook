# 材料缺口与待验证项

不把所有未读内容都叫作“缺资料”，也不为填表而广泛增加来源。

| ID | 类型 | 具体缺口 | 已有可用部分 | 后续最小动作 |
|---|---|---|---|---|
| G01 | 有理论，缺连续演奏教学 | 从四分柱式到八分分解再到十六分切分的双手、延音、力度与停音训练链 | S2 短节选、C2 L1–3/L7、S3 节奏记谱与分析 | 先设计原创小例，并由实际演奏验证；只有解释不足才定向补源 |
| G02 | 有正文，缺音乐验收 | 已读谱例并不等于已听、已弹、适合初学手型 | PDF、网页及部分本地媒体 | 写章时逐例验音高、拍值、音响、手感；本轮没有完成这些验收 |
| G03 | 有技能要求，缺公开教学正文 | Split/Layer、B3/EP 触键、现场预设管理与故障处理 | C5 大纲、S4 合成与路由概念 | 该阶段再用官方乐器/宿主文档定向补源，不把大纲扩写成假想课程 |
| G04 | 缺已核实的目标风格案例 | 当前阅读的歌曲案例以英文 pop/rock/jazz 为主，不是 J-pop/ACG 原曲语料调查 | 可迁移的和声、节奏、织体框架 | 后续挑少数代表曲，核对实际音源/授权乐谱；本轮不推断流行程度或杜撰和声 |
| G05 | 已获取但未实读 | OMT2 非核心章节；520 页合并习题册的大部习题；各类附件不是全部读过 | 全本 PDF、当前网页快照、正文/附件索引 | 按写作需要继续读，不能登记为“全本已读” |
| G06 | 媒体访问与版本边界 | HTML/PDF 无法自动保存嵌入播放器的所有功能；合并习题册是静态版，官网标为 2025-09-01 更新 | 当前页、原始 PDF、官方可下载附件、外链清单 | 优先使用章节末尾的当前习题链接；保留离线文件与在线版本差异 |
| G07 | 原文准确性 | 分类、符号和语境的疑点已经出现 | [source-issues.md](source-issues.md) | 针对将要引用的命题交叉核对，不整段照抄 |
| G08 | 自学反馈设计 | PULSE 教案依赖教师、视频、课堂提问和反馈；不能直接变成人类自学书 | 五份教案与五份视频转写均已取得和阅读，视频未观看 | 未来设计可观察的错误诊断与答案；不把转写中的演奏占位说明当作已听取示范 |
| G09 | 工具不具备领域校验 | GitHub 造书工具的图谱、字数、测验检查不验证音乐正确性 | 已读工作流与可借鉴结构 | 未来另设音名拼写、低音/转位、拍值、MIDI/MusicXML 与听觉/演奏核对 |

本轮没有新增商业教程或第三方音乐笔记作为正文源。公开仓库也不转载受版权保护的整本资料。
