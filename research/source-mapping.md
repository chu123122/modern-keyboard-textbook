# 主题与已读来源定位

| 20 | [Major Scales, Scale Degrees, and Key Signatures](https://viva.pressbooks.pub/openmusictheory/chapter/major-scales/) | 大调音阶、音级、调号与五度圈；移调保留关系。 |
| 21 | [Minor Scales, Scale Degrees, and Key Signatures](https://viva.pressbooks.pub/openmusictheory/chapter/minor-scales/) | 三类小调音阶、同主音与关系调；小调实践不等于永远只用自然小调。 |
| 22 | [Introduction to Diatonic Modes and the Chromatic Scale](https://viva.pressbooks.pub/openmusictheory/chapter/intro-to-diatonic-modes-and-the-chromatic-scale/) | 以同主音比较调式、五声音列与半音阶；保留色彩与语境。 |
| 24 | [Intervals](https://viva.pressbooks.pub/openmusictheory/chapter/intervals/) | 音程度数与性质要分开；等音、复音程与转位不同。 |
| 25 | [Triads](https://viva.pressbooks.pub/openmusictheory/chapter/triads/) | 三和弦按三度重排识别；重复、开放排列不改变根音和性质。 |
| 26 | [Seventh Chords](https://viva.pressbooks.pub/openmusictheory/chapter/seventh-chords/) | 七和弦由三和弦性质及七度性质共同决定；半减与减七分开。 |
| 27 | [Inversion](https://viva.pressbooks.pub/openmusictheory/chapter/inversion/) | 整体最低音决定转位；A♭mi/C 标签和 C♭ 步骤矛盾已登记。 |
| 28 | [Roman Numerals](https://viva.pressbooks.pub/openmusictheory/chapter/roman-numerals/) | 罗马数字依调性/根音；排列、配器和节奏不由级数标签充分表达。 |
| 44 | [Introduction to Harmony, Cadences, and Phrase Endings](https://viva.pressbooks.pub/openmusictheory/chapter/intro-to-harmony/) | 古典功能和乐句终止框架；需限定风格，不作为所有 pop 的强制句法。 |
| 45 | [Strengthening Endings with V⁷](https://viva.pressbooks.pub/openmusictheory/chapter/strengthening-endings-with-v7/) | V7 的倾向音与不完整解决；属于四声部教学语境。 |
| 47 | [Embellishing Tones](https://viva.pressbooks.pub/openmusictheory/chapter/embellishing-tones/) | 经过、辅助、倚音、逃音、挂留、先现、持续音；用于解释旋律与和弦关系。 |
| 58 | [Tonicization](https://viva.pressbooks.pub/openmusictheory/chapter/tonicization/) | 副属与主音化；先找目标和弦，再推导临时属和弦。 |
| 72 | [Modal Mixture](https://viva.pressbooks.pub/openmusictheory/chapter/modal-mixture/) | 借自同主音调式；区别根音变化前置记号与和弦性质。 |
| 85 | [Swing Rhythms](https://viva.pressbooks.pub/openmusictheory/chapter/swing-rhythms/) | Swing 比例会随风格/速度变化；2:1 是教学近似。 |
| 86 | [Chord Symbols](https://viva.pressbooks.pub/openmusictheory/chapter/chord-symbols/) | 和弦符号是演奏标签；add、sus、扩展及非和弦低音要分开。 |
| 87 | [Jazz Voicings](https://viva.pressbooks.pub/openmusictheory/chapter/jazz-voicings/) | 低音区疏、上方相对密；共同音与小幅移动；省略音依编制与风格。 |
| 88 | [ii–V–I](https://viva.pressbooks.pub/openmusictheory/chapter/ii-v-i/) | ii–V–I 可作为可变的 schema；包含副 ii–V 和 turnaround。 |
| 91 | [Chord-Scale Theory](https://viva.pressbooks.pub/openmusictheory/chapter/chord-scale-theory/) | 和弦—音阶是即兴选择框架；同性质有多种音阶，且本章明确其局限。 |
| 92 | [Blues Harmony](https://viva.pressbooks.pub/openmusictheory/chapter/blues-harmony/) | Blues 的属七性质可以承担 I/IV/V 功能，不能把性质等同于功能。 |
| 93 | [Blues Melodies and the Blues Scale](https://viva.pressbooks.pub/openmusictheory/chapter/blues-melodies-and-the-blues-scale/) | 问答与留白、大小 blues scale、blue notes；键盘固定音高只是近似。 |
| 94 | [Rhythm and Meter in Pop Music](https://viva.pressbooks.pub/openmusictheory/chapter/rhythm-and-meter-in-pop-music/) | 规则切分移位与 tresillo 分组不同；3+3+2 不等于三连音。 |
| 95 | [Drumbeats](https://viva.pressbooks.pub/openmusictheory/chapter/drumbeats/) | 鼓组记谱、backbeat、half/double time、kick/cymbal 分层；为合奏配合服务。 |
| 96 | [Melody and Phrasing](https://viva.pressbooks.pub/openmusictheory/chapter/melody-and-phrasing/) | 乐句重复/回应/离开/结尾；不是只增加音符数量。 |
| 97 | [Introduction to Form in Popular Music](https://viva.pressbooks.pub/openmusictheory/chapter/intro-to-form-in-popular-music/) | 核心/辅助段落、歌词与音乐变化、开闭性；结构边界有多类证据。 |
| 98 | [AABA Form and Strophic Form](https://viva.pressbooks.pub/openmusictheory/chapter/aaba-and-strophic-form/) | Strophic 与 AABA；refrain 是段内材料，不能与完整 chorus 混同。 |
| 99 | [Verse-Chorus Form](https://viva.pressbooks.pub/openmusictheory/chapter/verse-chorus-form/) | Verse、prechorus、chorus、postchorus、bridge 及循环组织。 |
| 100 | [Texture in Pop Music](https://viva.pressbooks.pub/openmusictheory/chapter/texture-in-pop-music/) | 按节拍、低音、和声、旋律、novelty 功能层组织编配，乐器可换角色。 |
| 101 | [Introduction to Harmonic Schemas in Pop Music](https://viva.pressbooks.pub/openmusictheory/chapter/intro-to-pop-schemas/) | 常用和声 schema 的总览及变体；不是唯一和弦进行词典。 |
| 102 | [Blues-Based Schemas](https://viva.pressbooks.pub/openmusictheory/chapter/blues-based-schemas/) | I–IV、IV–iv–I、double/extended plagal；下属方向可形成流行推进。 |
| 103 | [Four-Chord Schemas](https://viva.pressbooks.pub/openmusictheory/chapter/4-chord-schemas/) | Doo-wop、singer/songwriter、hopscotch 的顺序/旋转与调性歧义。 |
| 104 | [Classical Schemas (in a Pop Context)](https://viva.pressbooks.pub/openmusictheory/chapter/classical-schemas/) | Lament 与五度链；低音、根音与分析标签可能并非一一对应。 |
