# 写作任务与设计决定

日期：2026-10-27（Asia/Shanghai）。用户已授权完成必要的资料准备并开始写书；此前的“本轮不写正文”是历史阶段边界，已被本次明确请求更新。

## 本版交付范围

完成一部从初学基础到流行独奏、再衔接乐队的中文教材首稿，包含连续正文、原创双手五线谱、可听的合成参考、MIDI/MusicXML、练习与答案，以及可离线阅读的整书。以阶段作品检查整合能力，不以练习条目或任意速度作为统一等级。

本版定位为入门至早期应用教材，不宣称覆盖所有钢琴技术、完成商业歌曲编配或达到专业乐队演出标准。声音为程序合成参考，不是钢琴家录音；没有真人试教、动作检查或演奏验收时如实标明。

## 目标与来源

- 第一目标：键盘同时演奏旋律与伴奏，逐步独立学习喜欢的歌曲。第二目标：理解编制分工，开始乐队键盘配合。
- 伯克利 S1/S2 为主要技术、和声、练习和听觉参考；公开课程大纲校对顺序及覆盖，不冒充完整课内正文。
- OMT2 已读章节提供连续理论与概念核对。Bill Hilton 已取得讲义只作辅助参考；不继续扩大核心书目。Hoffman Academy 不作为本版依赖。
- 用户进一步明确现有资料足以启动写作：停止泛化补源，只有具体章节存在依据缺口或来源冲突时才定向核查。Integrated Musicianship 在旧交接中是暂不启用的备用候选，本地未取得、未实读，不列为已读核心源；本版无需等待它。
- 排除国内课程与笔记；不使用不明来源转载填补付费内容。
- 三组 GitHub 制作资料用于来源追踪、先修关系、样章检查和构建验证，不作为音乐事实或教学效果证据，也不安装运行其脚本。

## 写作顺序

1. 归档补充讲义、核对关键图谱，更新阅读范围。
2. 建立全书顺序与明确先修，先写“第一次双手配合”样章并生成对应谱例。
3. 核对该章音高、时值、可读性与示范的一致性，再完成其余章节。
4. 构建离线阅读版与印刷版；检查链接、谱面、MIDI、音频、来源和公开范围。
5. 同步状态与公开仓库，记录实际验证和未验收边界。

## 已确定的教学取舍

先补足读谱与节奏，再以伯克利 Keyboard Method 的读谱→双手→三和弦→连接→配置方向组织基础。练习曲从开头并行，不要求先掌握所有调。复杂爵士配置后置；旋律突出、伴奏简化、乐句、踏板与完整独奏前置到适当位置。

每章采用“目标声音—必要概念—明确操作—谱例—常见错误—变化与复习”的可读结构，避免把 AI 指令和工程信息混入学习正文。练习的保持与迁移要另查，不能用读懂答案或当天弹顺替代。

目标歌曲《ただ君に晴れ》的完整授权谱尚未取得。只提供经核实的官方选谱入口和学习迁移流程；不编造原曲分析，不将原创练习冒称原曲简化版。
