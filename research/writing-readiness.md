# 写作准备结论

2026-10-27更新：用户已确认以现有伯克利PDF、OMT2已读理论和正式课程大纲启动写作，停止泛化补源，并明确授权写书。现已编写首稿，入口见 `../book/index.html`，设计与验收边界见 `writing-plan.md`、`book-review.md`。以下为前一阶段的历史结论，不再限制本次已授权写作。

本轮完成的是资料获取、重点阅读和覆盖判断，不包含教材正文或样章。

## 可以进入下一步的部分

三和弦、根音/低音、转位/排列、音区、基本声部连接已有相互对照的正文来源。下一次若开始课程设计，可先围绕“在稳定节拍中把四个和弦连接成可弹奏伴奏”检验理论、键盘说明与可听例子能否衔接。

写作依据应来自 S3 已读基础/和弦章节、S2 pp. 5–10 与 77–86 的键盘材料、S1 的听觉和节奏方法；C1/C2 只用于能力覆盖核对。直接采用前先查看 [source-issues.md](source-issues.md)。

## 还不能声称完成的部分

- OMT2 全部 1,297 页与 520 页合并习题册未全本通读，非核心章节已有索引供后续读取。
- 音视频未完整聆听/观看，全部谱例没有逐一视觉核对，未实际弹琴或组织合奏验收。
- 整本书的正式目录、先修图和章内练习仍需设计；当前覆盖矩阵不等于已批准的课程。
- GitHub 仓库只读了指定制作文档，未审计全部代码，也未安装或运行其工作流。

## 下一阶段应如何约束质量

1. 先把每个学习目标对应到已读来源，区分事实、风格惯例和原创教学选择。
2. 为练习明确左右手、具体音高/八度、节拍、持续与停音方式；不只写“弹这个和弦”。
3. 原创 MIDI/MusicXML 的音高、拼写、时值可程序核验，音响与手感另作听觉/演奏核对。
4. 听觉与节奏从开头并行；从模仿、识别到变化，而非等理论读完再开始。
5. 公开版的原文改编、图片、谱例、歌曲和音频分别记录来源与许可；不把免费访问当作可整本转载。

本轮没有启动上述教材写作步骤。可直接从已保存的来源索引继续，避免重新搜集和重复下载。
